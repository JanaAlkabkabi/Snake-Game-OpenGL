
# 🐍 Snake Game – OpenGL

## 📌 Project Overview

A two-stage interactive Snake Game developed
using C++ and OpenGL as part of a Computer
Graphics course at Umm Al-Qura University.

## 🎮 Game Features

- Two interactive gameplay stages.
- Adjustable difficulty levels.
- Customizable map size.
- Food collection and score tracking.
- Bomb obstacles in Stage 2.
- Pause, restart, and menu navigation.
- Win and Game Over screens.

## 🕹️ Game Controls

| Key | Action |
|-----|--------|
| Arrow Keys | Move the snake |
| Enter | Start / Continue |
| P | Pause |
| R | Restart |
| M | Return to menu |

## 🛠️ Technologies Used

- C++
- OpenGL
- GLUT / FreeGLUT
